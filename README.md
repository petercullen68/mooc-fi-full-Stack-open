# Full Stack Open – Course Work

This repository contains my solutions and projects for the **Full Stack Open** course by the University of Helsinki.

## 📚 Course Overview

The course covers modern web development with a focus on:

* React (frontend)
* Node.js & Express (backend)
* REST APIs
* MongoDB
* TypeScript
* Testing and deployment

## ⚙️ Running Locally

Clone the repo:

```
git clone https://github.com/<your-username>/mooc-fi-full-stack-open.git
cd mooc-fi-full-stack-open
```

Navigate to a specific part:

```
cd part3/phonebook
npm install
npm run dev
```
